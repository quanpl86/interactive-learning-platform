# Product rules (normative)
- No scope creep beyond two courses' quick practice; local desktop projects always available by ZIP.
- Teacher must create a new lesson without editing source files after Authoring slice is complete.
- Every activity maps to objective and completion rule; self-check cannot fabricate test result.
- Every button is wired or disabled with explicit why; skeleton/prototype actions always labeled.
- Published releases immutable; editing creates draft or new version.
- Vietnamese primary language; English code identifiers permitted.
- All data about real students private; public content cannot contain teacher-only answers.
- Record actual status not aspirational success; update backlog only with test evidence.
