# Design rules (normative)
Read `docs/design/UI_UX.md`, `docs/design/tokens.json`, `ui-prototype/` before modifying UI. Light mode ONLY with explicit colors; avoid dark backgrounds even in editor except if user explicitly changes product requirement (currently not allowed). Flat, clean, solid surfaces, 1px borders, no gradient/glass/blur/strong shadow. White surfaces and neutral body; emerald primary and blue secondary. Layout responsive from 360px to desktop, breakpoints defined; no horizontal overflow except intentional code editor with proper scrolling. Minimum interactive target 44×44 where possible; visible focus, semantic controls, form labels, keyboard and caption support. No inert actions or decorative controls presented as enabled.
