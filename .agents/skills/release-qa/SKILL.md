# Release QA
Read acceptance and assigned slice. Run actual lint, TS, unit, integration, e2e, media probe and accessibility tests as applicable. Capture commands and exact results. Validate mock statuses remain labeled, real publish requires verified outputs, release pin/hash consistent, old release unchanged. Security review mandatory for iframe, upload or auth modifications. No claim of production deployment without verified deploy logs/URL. Report pass/fail/blocked separately.
