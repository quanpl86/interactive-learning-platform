# Local project flow
Template includes source + README setup + pinned runtime/dependencies + clean tests + checksums. Exclude `node_modules`, `.venv`, secrets, personal DB and large caches. Student downloads and practices locally; website does not claim IDE telemetry. On upload validate allowed extensions, ZIP size/unpack paths, quarantine, ownership, revision; teacher review. No automatic secure grade based solely on student-provided test output.
