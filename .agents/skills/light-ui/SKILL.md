# Light UI workflow
Read `docs/design/UI_UX.md`, tokens JSON and prototype. Work mobile 360 → tablet 768 → desktop 1280. Build semantic components, light editor theme `vs`, white surfaces, flat 1px borders, primary emerald. Avoid dark mode, gradients, shadows, glass, inaccessible icon-only buttons. Implement loading/empty/error/saved/pending states and accessible keyboard/focus/labels. Test 360, 768, 1280 and keyboard-only; record screenshots if tooling actually available.
